# 💰 배당 포트폴리오 모니터링 & 매매 저널 시스템

구글 스프레드시트와 노션 API를 연동하여 자산 보유 현황을 실시간으로 감시하고, 정밀한 가중 평균 평단가 연산 및 매매 복기 저널을 작성하는 투자 관리용 Streamlit 웹 어플리케이션입니다.

---

## 🚀 실행 및 운용 방법

### 1. 웹 어플리케이션 구동
로컬 가상환경 내에서 아래 Streamlit 명령어를 실행하여 웹 서비스를 켭니다.
```bash
streamlit run app.py
```

### 2. ⚙️ [관리자 도구] 테스트 데이터 완전 초기화 (Reset All Data)
테스트 시나리오 재검토 시 구글 시트와 노션을 깨끗한 최초 상태로 완전히 소거하고 리셋하기 위해 사용합니다. (현업의 안전 보안 수칙을 지키기 위해 오직 터미널 명령을 통해서만 실행됩니다.)
```bash
python reset_all_data.py
```
* **동작 내용**:
  - 구글 시트의 `portfolio`(보유), `order_history`(주문), `trading_history`(실현) 시트의 모든 행 데이터를 헤더만 남기고 완전 삭제합니다.
  - 노션 데이터베이스의 모든 페이지를 자동으로 감지하여 일괄 아카이브(휴지통 삭제) 처리합니다.
